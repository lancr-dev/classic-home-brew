The gallery markup, captions, alt text, and responsive image choices are in `index.html`. The `.look-*` component styles and named grid areas are in `style.css`. To change a photograph, update its `src`, `srcset`, dimensions, alt text, and caption together. Framing can be adjusted with the card’s `--look-position` custom property.
