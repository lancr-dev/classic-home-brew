# Menu illustration

`coffee-moments.svg` is original vector artwork made for Classic Home Brew. It uses the brand cream (`#F4EBDD`) for coffee cups, beans, a moka pot, a pour-over brewer, and a leafy sprig.

The illustration is decorative and scales without losing quality. Menu names, options, and prices remain editable text in `index.html`; styling is scoped to the menu component in `style.css`. Prices are shown in Philippine pesos (₱), as confirmed for this project.
